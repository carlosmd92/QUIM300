# Fisicoquímica Aplicada QUIM300

Libro de resúmenes de estudio de Fisicoquímica Aplicada. Cada capítulo reúne los contenidos de una parte del curso con ecuaciones, ejemplos resueltos y visualizaciones que responden al mover sus parámetros. Cada capítulo tiene un resumen en PDF para descargar y, dentro de su tema, una subpágina de autoevaluación.

Sitio web: https://carlosmd92.github.io/QUIM300/
